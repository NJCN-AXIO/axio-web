# AXIO 首发价格与微信宣传海报设计

日期：2026-07-20
状态：Approved for planning

## 目标

本次工作同时完成三个相互一致的公开销售触点：

1. 官网 /pricing 从“联系咨询式方案”调整为可直接理解的首发价格。
2. 输出两张 1080 × 1440 微信竖版海报：一张带价格，一张不带价格。
3. 输出一段与海报一致的朋友圈宣传文案。

本次不增加在线付款、账号注册、许可证自动发放、数据库或其他服务端能力。购买和演示仍通过微信沟通。

## 价格模型

官网、价格海报和朋友圈文案使用同一组价格：

| 方案         | 正式售价       | 首发售价    | 交付定位                                   |
| ------------ | -------------- | ----------- | ------------------------------------------ |
| Starter      | ¥999 / 年      | ¥399 / 年   | 标准客户端与基础流程，自助使用             |
| Professional | ¥1,999 / 年    | ¥699 / 年   | 完整自动化、精准控价、风险管控和标准支持   |
| Team         | ¥4,999 / 年    | ¥1,999 / 年 | 团队使用、优先支持和有限规则配置           |
| 定制部署     | 按范围报价     | ¥6,800 起   | 客户环境部署、配置与培训                   |
| 源码交付     | 单独报价       | 不设公开底价 | 明确代码范围、知识产权、适配与后续维护责任 |

Professional 是官网和价格海报的唯一主推方案。20 席专指 Professional 的首发名额，Starter 和 Team 不计入该名额；Professional 首发结束后应恢复正式售价，避免使用从未执行过的虚假“原价”。

第三方费用不包含在套餐中，包括妙手 ERP 授权、模型/API 调用、Windows 设备、网络和代理、Shopee 平台费用。

## 官网调整

### 套餐数据

- 保留 Starter 和 Professional。
- 将当前 Enterprise 改为 Team，避免把 ¥1,999/年的团队版误写成源码或私有化版本。
- 套餐数据新增正式售价、首发售价、首发标签和交付要点。
- 定制部署与源码交付作为三档套餐之外的独立说明，不进入 Team 的固定承诺。

### 价格页

- Hero 改为首发计划语境，明确当前是 Windows 本地客户端，不支持在线付款。
- 三张套餐卡同时展示正式售价和首发售价，Professional 具有清晰但克制的推荐状态。
- 正式售价不使用删除线伪装历史成交价；标签使用“正式售价”和“首发限量价”。
- 页面明确“首发 20 席”“具体交付以确认范围为准”“第三方费用不包含”。
- 所有购买按钮继续指向 /demo，命令文案为“预约演示”或“微信咨询”。
- 定制部署与源码交付使用独立横向说明区，不嵌套进套餐卡。

### 首页版本预览

首页继续展示三档方案，但同步 Starter、Professional、Team 名称与首发价格，防止首页和价格页出现两个版本体系。

## 海报系统

### 共同规格

- 画布：1080 × 1440，适合微信朋友圈和微信群。
- 输出：高质量 PNG；另提供体积更小的 JPEG 便于直接发送。
- 视觉语言：近黑背景、暖白正文、AXIO/Shopee 橙为主强调色，少量绿色表示安全和完成状态。
- 字体：使用系统可商用中文无衬线字体，标题粗体，正文保持手机端可读。
- 卡片圆角不超过 8px，不使用发光圆球、紫色渐变、无关装饰或生成的假数据。
- 借鉴用户参考图的信息层级和黑色高质感，但不复制 TikTok Shop 标识、图标、金色资产或具体构图。

### 共同内容结构

1. AXIO 智核品牌与 Shopee 专属定位。
2. 主标题和一句价值主张。
3. task-pricing.webp 真实产品界面作为主视觉，标注“实机界面”。
4. 六项核心优势：
   - Shopee 店群运营
   - 自然语言任务编排
   - 透明公式精准控价
   - 妙手 ERP 批量执行
   - 违禁与图片风险管控
   - 结果回读与矩阵经营
5. Windows 本地运行与敏感凭证边界。
6. wechat-nay.webp 微信二维码和“扫码预约演示”。

海报不展示真实店铺数量、站点数量、账号、订单、利润或平台凭证。

## 验收标准

### 官网

- /pricing 和首页均显示 Starter、Professional、Team。
- 三档首发价分别为 ¥399、¥699、¥1,999 每年。
- 三档正式价分别为 ¥999、¥1,999、¥4,999 每年。
- Professional 是唯一推荐方案。
- 定制部署 ¥6,800 起和源码交付单独报价有独立说明。
- 页面不提供在线支付，也不暗示账号、数据库或云端 SaaS 已上线。
- 单元测试、类型检查、Lint、格式检查和静态构建通过。

### 海报

- 两张 PNG 均为 1080 × 1440，JPEG 尺寸一致。
- 微信二维码可被常见扫码工具识别。
- 中文文字逐字核对，无生成乱码、错字或额外字符。
- 产品界面来自现有脱敏证据图，手机端能辨认主要结构。
- 价格版和官网价格完全一致；品牌版不出现任何价格。
- 海报不包含 TikTok Shop 标识或参考图中的受保护视觉资产。

## 非目标

- 不制作抖音、小红书、横版 Banner 或打印出血版本。
- 不新增在线支付、订单、注册、登录或许可证发放。
- 不承诺永久买断、无限支持、无限店铺或无限定制。
- 不修改 AXIO 产品仓库，只修改官网仓库和公开宣传素材。
