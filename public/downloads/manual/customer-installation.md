# AXIO 客户安装手册

## 安装前准备

确认电脑运行 Windows 10/11 x64，并已安装 Chrome 和 VC++ 2015–2022 运行库。客户包已经包含应用运行时，不需要安装 Python。下载后先核对官网版本卡中的文件名、大小、SHA-256 和发布签名；任一项不一致都停止安装并联系 AXIO。

## 安装步骤

1. 将经过校验的 ZIP 解压到固定的独立版本目录，不要在 ZIP、移动硬盘、下载缓存或临时目录中直接运行。
2. 按安装程序提示安装发布与许可公钥、创建本地数据目录并完成环境检查。
3. 在本机复制安装码，通过约定渠道获取设备绑定的离线许可文件，再回到客户端导入。
4. 配置客户自己的模型 Provider，完成文本和视觉能力测试。
5. 下载五类空白 CSV 模板，填写客户自己的店铺、商品、类目、关键词和定价参数。
6. 每次导入都先预览和校验；确认有效行后才写入客户数据库。
7. 在客户自己的 Chrome 中登录平台并检查妙手插件、浏览器角色与端口状态。
8. 运行首轮只读健康检查，确认数据、许可和环境状态后再开放受控任务。

## 升级与回滚

新旧版本必须并排保留。升级前创建备份，在新目录完成迁移和健康检查后再切换；迁移失败时继续使用旧版本和原备份。删除旧版本目录前必须确认客户数据位于独立数据目录，并且新版本已经通过业务回读。

## 安全边界

不要向官网、聊天工具或客服发送店铺密码、浏览器会话、完整业务数据或本地凭据。验证码、登录过期、签名异常、授权异常和未知平台写入都会失败关闭；先按客户端提示恢复或只读对账，不自行重复提交。
