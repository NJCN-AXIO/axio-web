# AXIO API 配置手册

## 配置原则

AXIO 不附带共享模型凭据。Provider 账号、额度、账单和访问凭据由客户自行管理，并只在客户本机客户端中填写。官网和客服无法读取本地凭据；不要把凭据复制到聊天、截图、邮件、导入模板或诊断包中。

## 必填字段

- Provider：客户选择的模型服务商或受支持的本地服务。
- Base URL：服务商提供的 HTTPS 地址；不接受明文 HTTP 或脚本协议。
- Model：已在客户账号中开通且与任务能力匹配的模型名称。
- 文本能力：用于标题、描述、分类建议等文本任务。
- 视觉能力：用于明确需要图片理解的任务；不支持时保持关闭。
- 访问凭据：只保存到客户端本地凭据存储，不写入 CSV、日志或官网。

## 测试顺序

1. 保存 Provider、Base URL 和 Model 后先运行连接测试。
2. 单独运行文本能力测试，确认权限、余额、超时和返回格式。
3. 需要视觉能力时再运行视觉测试，失败不会自动降级成未经确认的文本结果。
4. 只有测试通过的能力才可用于依赖它的任务；普通确定性功能不依赖模型时仍可继续使用。

## 故障恢复

余额不足、权限错误、证书错误或能力不匹配时，客户端隔离对应 Provider 并停止依赖任务，不伪装成功。修复账号或配置后重新运行能力测试。第三方模型费用由客户与服务商结算，不包含在 AXIO 套餐内；客户明确发起调用时，只发送完成该次任务所需的最小内容。
